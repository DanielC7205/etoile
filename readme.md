# ⭐️ Etoile | And the stars say I love you
Etoile (or star in French) is a Jellyfin music client designed to allow you to listen to music under the stars.

## Generating Xcode Project
- Etoile requires [Xcodegen](https://github.com/yonaskolb/XcodeGen) to generate the Xcode project. Install it using Homebrew.
- Update Makefile to have an Apple Development Team ID
- Next run `make xcodegen` to generate the Xcode Project with the correct version
